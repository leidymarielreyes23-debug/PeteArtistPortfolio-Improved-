📝 Implementation Plan and Design Decisions
1. Header
Used Flexbox to align the logo and navigation horizontally.
Centered elements vertically.
Used a navy blue background and cream-colored text.
Improved spacing between elements.
2. About Section
Used Flexbox to position Pete's image and introduction side by side.
Centered the heading and left-aligned the paragraph.
Placed Pete's Background underneath in a separate cream-colored container with rounded corners.
3. Portfolio Section
Used Flexbox to arrange the three projects horizontally.
Added cream-colored backgrounds and rounded corners.
Set project descriptions to 14px.
Maintained the original fonts and color palette.
Design Trade-offs
I maintained the original colors and fonts to preserve the website's identity. I prioritized a clean horizontal layout over adding unnecessary visual effects, focusing on readability, consistency, and organization.

------------------------------------------

🐛 Challenges, Debugging, and Learning
My main challenges involved aligning elements, organizing HTML containers, and controlling spacing between sections.
I adjusted Flexbox properties, margins, padding, and alignment to achieve the desired layouts.
I learned the importance of applying Flexbox to the correct parent container and how small CSS adjustments can improve the overall appearance of a website.
